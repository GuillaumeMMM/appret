`TabsController` turns your own markup into an accessible set of tabs, following the
[WAI-ARIA tabs pattern](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/).

## Examples

### Labelling

A text `label` adds an `aria-label` attribute to the list. If the tabs must be labelled by an existing text somewhere else on the page, use `label: { byId }` with the ID or IDs of a visible label.

When the label is outside your component's shadow root where IDs can't reach, or when it has no ID, use `label: { byElements }` with a list of elements.

## Reference

### Config

| Property | Type | Default | |
| --- | --- | --- | --- |
| `list` | `HTMLElement` | | The tabs container. |
| `tabs` | `HTMLElement[]` | | The tabs. |
| `panels` | `HTMLElement[]` | | One panel per tab in the same order. |
| `label` | `string \| { byId: string } \| { byElements: Element[] }` | | A text for `aria-label`, space-separated IDs for `aria-labelledby`, or labelling elements, also outside the shadow root. |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | Which arrow keys move between tabs. |
| `selectionFollowsFocus` | `boolean` | `true` | Whether moving focus also selects the tab and opens the panel. |
| `loop` | `boolean` | `true` | Whether keyboard navigation wrap around at the ends. |
| `initialSelection` | `HTMLElement \| number` | first non-disabled tab | Tab (or index of the tab) selected at setup. |

### Methods and properties

| | |
| --- | --- |
| `select(tab \| index)` | Selects a tab. Doesn't move focus or fire an event. |
| `selectedTab` | Gets the selected tab. |
| `selectedIndex` | Gets the selected tab index in `tabs`. |
| `update(config)` | Applies changes to the config (for example new `tabs` and `panels`). |
| `focus()` | Moves focus to the selected tab. |
| `destroy()` | Removes listeners and restores the original markup. |

## WAI-ARIA pattern

Requirements of the [WAI-ARIA tabs pattern](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/).

### Roles, states and properties

| Requirement | Status | Notes |
| --- | --- | --- |
| The tab container has role `tablist`. | <span role="img" aria-label="Implemented">✅</span> | |
| Each tab has role `tab` and is inside the `tablist`. | <span role="img" aria-label="Implemented">✅</span> | |
| Each panel has role `tabpanel`. | <span role="img" aria-label="Implemented">✅</span> | |
| The `tablist` is labelled: `aria-labelledby` for a visible label, otherwise `aria-label`. | <span role="img" aria-label="Implemented">✅</span> | |
| Each tab has `aria-controls` pointing to its panel. | <span role="img" aria-label="Implemented">✅</span> | |
| The active tab has `aria-selected="true"`, the others `"false"`. | <span role="img" aria-label="Implemented">✅</span> | |
| Each panel has `aria-labelledby` pointing to its tab. | <span role="img" aria-label="Implemented">✅</span> | |
| A tab with a popup menu has `aria-haspopup` set to `menu` or `true`. | <span role="img" aria-label="Left to the author">❌</span> | The popup belongs to your code, the controller leaves it untouched. |
| A vertical `tablist` has `aria-orientation="vertical"`. | <span role="img" aria-label="Implemented">✅</span> | |

### Keyboard interaction

| Requirement | Status | Notes |
| --- | --- | --- |
| <kbd>Tab</kbd> into the tab list moves focus to the active tab. | <span role="img" aria-label="Implemented">✅</span> | |
| <kbd>Tab</kbd> from the tab list moves focus to the next element, usually the panel. | <span role="img" aria-label="Implemented">✅</span> | Panels get `tabindex="0"`, unless you set your own `tabindex`. |
| <kbd>Left Arrow</kbd> / <kbd>Right Arrow</kbd> move to the previous / next tab, wrapping at the ends. | <span role="img" aria-label="Implemented">✅</span> | Swapped in right-to-left. Disabled tabs are skipped. `loop: false` disables wrapping. |
| <kbd>Space</kbd> or <kbd>Enter</kbd> activate the focused tab, when tabs aren't activated on focus. | <span role="img" aria-label="Implemented">✅</span> | With `selectionFollowsFocus: false` |
| <kbd>Shift</kbd> + <kbd>F10</kbd> opens the tab's popup menu, if any. (Optional) | <span role="img" aria-label="Left to the author">❌</span> | The popup belongs to your code, the controller leaves it untouched. |
| <kbd>Home</kbd> moves to the first tab. (Optional) | <span role="img" aria-label="Implemented">✅</span> | Skips disabled tabs. |
| <kbd>End</kbd> moves to the last tab. (Optional) | <span role="img" aria-label="Implemented">✅</span> | Skips disabled tabs. |
| <kbd>Delete</kbd> closes the current tab and moves focus to the following tab, if closing is allowed. (Optional) | <span role="img" aria-label="Left to the author">❌</span> | Removing tabs is your decision. |
| In a vertical tab list, <kbd>Down Arrow</kbd> and <kbd>Up Arrow</kbd> act as <kbd>Right Arrow</kbd> and <kbd>Left Arrow</kbd>. | <span role="img" aria-label="Implemented">✅</span> | <kbd>Left Arrow</kbd> and <kbd>Right Arrow</kbd> keep working too. |
| Tabs should be activated on focus when panels show without noticeable delay. | <span role="img" aria-label="Implemented">✅</span> | |
