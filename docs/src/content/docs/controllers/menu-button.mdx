`MenuButtonController` turns your own button into a button that opens a menu, following the
[WAI-ARIA menu button pattern](https://www.w3.org/WAI/ARIA/apg/patterns/menu-button/).

<Demo><Basic /></Demo>

## Usage

Pass a host element, the button and the menu. Pass a [`MenuController`](/controllers/menu/) too, to move focus into the menu and close it with the menu's keys.
