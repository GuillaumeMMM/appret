`<appret-listbox>` is a custom element that wraps your HTML and makes it a listbox following the [WAI-ARIA listbox pattern](https://www.w3.org/WAI/ARIA/apg/patterns/listbox/) using the [Apprêt listbox controller](/controllers/listbox/). It finds its parts in your markup from `data-appret-part` attributes. It adds no styles and no shadow DOM.

<Basic />

## Usage

Load the element once, from a CDN or with a bundler:

```html
<script type="module" src="https://cdn.jsdelivr.net/npm/appret/dist/define/listbox.js"></script>
```

```js
import "appret/define/listbox";
```

Then mark the parts of your markup:

## Reference

### Parts

| `data-appret-part` | |
| --- | --- |
| `listbox.list` | Options container. |
| `listbox.option` | An option, inside the list or a group. |
| `listbox.group` | A group of options, inside the list. Optional. |
| `listbox.group-label` | The label of a group, inside it. Optional. |

### Attributes

| Attribute | Type | Default | |
| --- | --- | --- | --- |
| `label` | `string` | | Accessible name of the list. |
| `labelledby` | `string` | | Space-separated IDs of elements labelling the listbox. |
| `orientation` | `"horizontal" \| "vertical"` | `"vertical"` | |
| `selection-follows-focus` | `boolean` | `false` | Whether moving focus also selects the option. Ignored with `multiple`. |
| `multiple` | `boolean` | `false` | Allows selecting several options. |

### Properties and methods

| | |
| --- | --- |
| `select(option \| option[] \| null)` | Replaces the selection. `null` clears it. |
| `selectedOption` | Gets the first selected option. `null` when there is none. |
| `selectedOptions` | Gets the selected options. |
| `focus()` | Moves focus to the active option (reachable with <kbd>Tab</kbd>). |

## WAI-ARIA pattern

Keyboard support follows the [WAI-ARIA listbox pattern](https://www.w3.org/WAI/ARIA/apg/patterns/listbox/), as described for the [listbox controller](/controllers/listbox/).
