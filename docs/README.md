# Apprêt docs

The documentation site for Apprêt, built with [Starlight](https://starlight.astro.build).

Pages live in `src/content/docs/`, and live examples in `src/examples/`: each example file is both the demo and the code shown.

From the repository root:

| Command | Action |
| --- | --- |
| `npm run docs:dev` | Start the docs at `localhost:4321` |
| `npm run docs:build` | Build the docs to `docs/dist/` |
| `npm run dev` | Rebuild the library and run the docs together |
